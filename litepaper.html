Canonical Base deployment and release model

1. Canonical Deployment

Aetheron's canonical AETH token is deployed on Base Mainnet (chain ID 8453).

2. Platform Direction

Aetheron is a DeFi-oriented platform focused on wallet connectivity, transparent on-chain status, analytics, portfolio tooling, governance surfaces, and carefully gated staking/trading integrations.

The production website is designed to fail closed when launch authorization is incomplete or the connected network is not the canonical Base network.

3. Release Safety

Deployment of a token does not by itself authorize a presale, public-funds flow, staking contract, trading enablement, or liquidity position.

  • Public presale funding remains disabled pending final authorization.
  • Trading remains disabled pending final authorization.
  • Canonical mainnet liquidity must not be added before the release gate is satisfied.
  • Production staking must not be represented as live until its Base deployment, source verification, roles, and economics are independently reviewed.

Current status is published on the AETH launch-status page.

4. Verification Model

Release evidence should be independently reproducible. The project uses canonical deployment manifests, explorer evidence, CI safety gates, source/bytecode verification, role review, and explicit written authorization before financial launch actions.

Users should independently verify the chain, contract address, current authorization state, and transaction destination before signing anything.

5. Historical Networks

Older Polygon and Mumbai references are historical records only. They are retained in repository history or explicitly archived material where useful, but they are not production deployment truth and are excluded from the current production website bundle.

6. Risk

Blockchain applications and digital assets involve technical, market, smart-contract, wallet, and regulatory risks. No interface or historical document should be treated as a guarantee of returns or as authorization to send funds.
